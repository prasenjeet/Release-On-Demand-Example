⚙ Feature Flag Management

Toggle features on or off without deploying code. Changes take effect immediately — flagd hot-reloads flags/flags.json.

📖 Release on Demand

Code is deployed continuously to production, but features are released on demand via feature flags. This decouples deployment from release, enabling:

  • Dark launches — test with real traffic before users see it
  • Canary releases — roll out to a % of users gradually
  • Targeted rollouts — release to beta users by email or role
  • Instant rollback — flip a flag, no deployment needed
